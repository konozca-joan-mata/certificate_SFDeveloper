## 📁 Estructura del Proyecto (Developer)

La enciclopedia se organiza en los 4 pilares del examen PDI:

1. **Fundamentos de Desarrollo (23%)**: Tipos de datos, colecciones, SOQL y SOSL.
2. **Lógica Apex & Automatización (30%)**: Triggers, Order of Execution y Governor Limits.
3. **User Interface (25%)**: Lightning Web Components (LWC) y Visualforce.
4. **Testing & Despliegue (22%)**: Clases de Test, Sandboxes y ALM.

---

## 🛠️ Características Técnicas

* **Code Focus**: Incluye bloques de código con resaltado sintáctico (estilo Dark Mode).
* **Governor Alerts**: Cajas rojas especiales que resaltan los límites críticos de la plataforma.
* **Order of Execution**: Lista detallada de los 20+ pasos que sigue Salesforce al guardar un registro.
* **Design Pattern Friendly**: Enfocada en buenas prácticas como la Bulkificación y el patrón Handler.
